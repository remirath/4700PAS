# TWM Waveguide and Laser Simulator 

This repository contains a MATLAB-based simulator developed for modeling transient and frequency-domain behavior of optical waves propagating through a 1D waveguide with Bragg-reflector gratings.
The simulatior uses numerical equations from the Traveling Wave Model (TWM) with implied Bragg-reflectors as the boundary.

The simulator was developed as a semester-long project and coursework tool. 

- Bragg reflection and transmission
- Transient dynamics of signal evolution
- Frequency response analysis
- Effects of phase mismatch and grating strength

This tool is intended to be used by students.

## Features

- Numerical solution of coupled-mode equations
- Time-domain and frequency-domain analysis
- Customizable waveguide and grating parameters
- Visualization of signal power evolution and spectral response

- `lasermodel.m` — **Main script** that sets up parameters and runs the simulation.
